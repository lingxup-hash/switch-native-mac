# 旷野之息1.6.0原生金手指

Swift/AppKit界面＋Python/LLDB后台，提供13项固定功能。当前为本机实验工具，包含 `/Volumes/SwitchNative` 等硬编码路径；还不是可直接安装到任意Mac的发行版。不要只改版本显示文字就对另一个游戏构建运行。

## 怎么理解操作

- **检查目标**：只读当前目标，不会修改数量。
- **执行所选功能**：单次写入；消耗之后数值仍会下降，不是无限锁定。
- **恢复本次修改**：恢复当前进程所记录的原值，不是撤销已保存的存档。进程变化、物品消失或身份不符会拒绝恢复。
- **当前箭**：已装备的箭，不是背包光标所在的箭。先在游戏中装备目标箭，再检查数量；例如普通箭997、炸弹箭209时，检查997说明还没切换到炸弹箭。
- 四种弓效果互斥；其他装备操作前打开背包。

已修复按箭种分别记录原值、按背包内原箭种恢复；旧版单一 `arrows` 记录能迁移。实际炸弹箭执行和恢复的完整回归仍未完成，连接阶段曾闪退。界面还未显示箭种名称，使用前核对数量。

## 验证范围

| 类别 | 证据 |
|---|---|
| 材料 | 苹果230→999界面确认；137种已有材料批量写入回读，用户看见效果；执行过恢复 |
| 卢比、生命 | 数值与界面确认，单次修改 |
| 武器／弓／盾耐久 | 大数值回读和菜单切换保留，未证明永不损坏 |
| 攻击、盾强化、弓词条 | 游戏显示已确认；部分射速、实际伤害未单独测量 |
| 箭种切换修复 | 自动测试通过；不要把它称作全部游戏内验收通过 |

只修改已有材料，不创建未收集物品；不把武器替换成材料。完整历史见仓库 `docs/`。

## 无游戏测试

从仓库根目录执行，两个入口均应运行全部13项测试：

```sh
python3 cheats/botw-trainer/test_core.py
python3 -m unittest discover -s cheats/botw-trainer -p 'test_*.py' -v
```

这些测试不连接游戏、不读密钥，也不证明LLDB连接稳定。不要运行 `bridge.py apply` 来代替单元测试。
