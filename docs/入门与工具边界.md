# 准备与使用边界

## 先选择路线

| 游戏 | 使用的上游 | 当前定位 |
|---|---|---|
| 旷野之息1.6.0、王国之泪1.2.1 | MacNativeGames | 已有原生应用，仍有已知问题；具体版本不能随意互换 |
| 马力欧卡丁车8豪华版4.0.1 | mush8 | 用户完成过一局比赛；3.0.3 ARM32研究不等于可用构建 |
| 超级马力欧派对 空前盛会2.2.0 | nxnative＋NRO相关改动 | 研究版；按本仓库固定版本复现指南操作 |
| 喷射战士3 9.3.0 | nxnative静态分析 | 项目已停止，没有可玩原生构建 |

链接：[MacNativeGames](https://github.com/ly05010419/MacNativeGames)、[mush8](https://github.com/c22dev/mush8)、[nxnative](https://github.com/seedds/nxnative)。上游会变化，复现应记录提交，不应直接把最新版本与旧地址补丁混用。

## 环境

已使用的环境是 Apple Silicon Mac、Xcode及Metal工具链、Homebrew、Python独立环境。nxnative另外使用 .NET10、lz4、capstone、fonttools、zstd、spirv-cross、glslang、xcodegen。按各上游的固定版本说明安装；不要为补一个依赖盲目重装整个环境。

外置盘上的编译目录建议使用APFS；本次使用ExFAT物理盘内的APFS稀疏镜像。镜像的最大容量不是物理盘的可用空间，两者都需要检查。游戏输入、提取文件、缓存和运行存档分开存放；升级前备份存档。

## 工具成熟度

- `tools/run/`：本机操作记录，很多路径硬编码；先阅读再替换成自己的目录。
- `tools/xci/list_xci.py`：列出容器，不能单独证明下载完整或游戏可运行。
- `tools/xci/split_xci.py`：派对整合包的历史专用脚本，读取脚本旁的 `container.json`，输出名称和版本硬编码。依据元数据条目位置分组，不是通用CNMT解析器。
- `tools/xci/split_groups.py`：根据输入清单中的组号拆出一组，不负责验证组号、真实版本和游戏对应关系。
- `tools/xci/prepare_inputs.py`：早期未跑通的提取实验，不作为推荐入口。
- `tools/re/`、`cheats/botw-research/`：诊断脚本，可能包含固定版本地址和本机路径，不应直接对其他版本运行。

## 校验的三层含义

1. 下载器预分配的文件也可能显示完整大小：先确认下载任务完成，不能仅凭大小判断。
2. NCA整体SHA-256前16字节与文件名比较，仅是文件名哈希检查。匹配不能替代CNMT内容哈希、NCA分区哈希树验证；不匹配也不能直接认定只有头部被改写。
3. 提取器严格校验只覆盖它实际读取的区块。survey主要读取代码及文件清单，不等于所有RomFS数据验证通过。

拆分脚本在哈希不符时仍保留输出用于研究，现在最终JSON会如实报告 `MISMATCH`。即使输出 `PASS`，`content_integrity_verified` 也保持false。不要把输出存在、提取成功或编译成功称为游戏可玩。

本仓库不提供游戏文件、密钥、固件或下载来源。使用自行取得且有权使用的输入；诊断日志在分享前删除密钥、票据、账号及私人路径。旧工具的警告可能回显密钥，不可原样贴出。
