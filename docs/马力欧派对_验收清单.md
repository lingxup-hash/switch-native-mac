## 影片输出槽补丁回归

`0002`修改的是共用movie逻辑。派对的一次片头通过，不能证明所有调用方式都安全。

- [ ] 原生纹理模式：GetOutputBuffer拷贝完成后及时归还槽，输入/输出队列不再耗尽。
- [ ] 显式释放模式：仍按原语义归还，不提前复用仍被持有的帧。
- [ ] 重复释放与槽号复用：延迟释放不会误释放后来被重新获取的同号槽；`held`布尔标记本身不是完整代际证明。
- [ ] Flush/Stop/重新开始：旧输出、待解码输入与EOS/drain状态正确清理。
- [ ] 播片结束、跳过、连续第二段与循环播放：不会卡在最后一帧或永久等待。
- [ ] 分辨率变化、音视频同步、多线程调用：按可获得的合法输入做对照。
- [ ] 其他mode-2游戏回归：记录具体游戏和版本；Big Brain Academy/Metroid Dread只是候选对照，不是已通过记录。

可先用自行编写的队列状态测试覆盖边界，再进行游戏内对照；工具测试、影片通过、完整玩法通过分别报告。

公开发布仅包含自写代码、配置说明和适当脱敏的结论，不提交游戏模块、shader产物、存档或密钥。已有本地敏感日志不要直接整份粘贴到Issue。
