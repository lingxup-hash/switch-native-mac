## 项目环境

开始工作时执行：

```sh
source /Volumes/SwitchNative/Tools/switch-env.sh
```

下载缓存：/Volumes/SwitchNative/Cache/Homebrew
临时文件：/Volumes/SwitchNative/Temp
源码：/Volumes/SwitchNative/Projects
游戏输入：/Volumes/SwitchNative/GameFiles
构建：/Volumes/SwitchNative/Builds
应用：/Volumes/SwitchNative/Apps

系统编译工具及 Homebrew 依赖使用 macOS 标准安装位置。
