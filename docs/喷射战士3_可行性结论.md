## 判断
- 技术面比派对好：没有 NRO，引擎与框架已在做的几款同族，着色器格式是框架熟悉的 bfsha。主要风险是 SDK 13 的结构差异（框架有 SDK 4.4 与 20.x 的同族游戏，13 夹在中间，要逐项核）。
- **玩法面最大限制：喷射3 的核心是联网对战，原生版不会有联网**。离线能玩的只有英雄模式（剧情）、打工练习/单人部分、占地对决 vs 电脑，以及 DLC「秩序之塔」（需要拆 DLC）。
